# Disclaimer

Dit project is een **experimentele Proof of Concept (PoC)**: een invulhulp die
overheidsmedewerkers helpt bij het invullen van compliance-formulieren. De code
is **grotendeels gegenereerd met generatieve AI** (Claude Code, Anthropic).

## Geen officiële dienst

Deze repository is geen productiesysteem en geen officiële overheidsdienst. Het
dient om te leren en te experimenteren. Aan de inhoud of werking kunnen geen
rechten worden ontleend.

## Uitgangspunt: alle commits zijn met AI gegenereerd

Ga ervan uit dat elke commit in deze repository met behulp van Claude Code tot
stand is gekomen, ook als dat niet apart in de commit staat. De persoon die de
commit maakt, blijft verantwoordelijk voor de inhoud ervan: die heeft de
wijziging beoordeeld en goedgekeurd voordat die in de repository is opgenomen.

## Gebruik van generatieve AI

Overheidsorganisaties die generatieve AI inzetten — waaronder het gebruik van
deze code en de output die ermee wordt gegenereerd — dienen te voldoen aan het
[Overheidsbreed standpunt voor de inzet van generatieve AI](https://open.overheid.nl/documenten/bc03ce31-0cf1-4946-9c94-e934a62ebe73/file)
en aan eigen beleid en kaders over AI.
